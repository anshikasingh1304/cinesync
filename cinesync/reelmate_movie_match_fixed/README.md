# Reelmate — Movie Social MVP

Open `index.html` in a browser.

This is a polished, functional front-end prototype:
- Campus vs Open registration
- Campus discovery: same college vs all colleges
- Offline friend search + movie request + accept flow
- Shared genre selection
- Tinder-style movie swiping + match screen
- Online movie/series swiping
- Top 3 taste-based people
- Working chat UI with demo replies
- Matches page and profile page

Important: this prototype uses browser state only. For real multi-device accounts, verification, persistent friend requests, real-time matching, and real chat, connect a backend such as Supabase and a movie data API.
