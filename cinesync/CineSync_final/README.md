# CineSync

A polished browser-only prototype for matching people through movie taste.

## What's included
- New CineSync branding with a cute DNA-inspired mark
- Dark cinematic dashboard inspired by the provided visual direction
- Campus vs open-community registration
- Campus discovery choices: my college, all colleges, or open community
- Offline movie-night flow with friend request, genre selection, shared swiping, and match screen
- Online discovery flow with movie swiping, top-3 taste matches, and chat UI
- Profile, matches, discover, and chat views
- Responsive desktop/tablet/mobile layout
- Mode switching between offline and online while swiping

## Run
Open `index.html` in a modern browser. This is a front-end prototype, so data is kept in browser memory and demo users/movies are included.


Theme: use the ☾/☀ controls in the top bar to switch between the cinematic dark theme and the elegant light theme. Your choice is saved in the browser.
